1. INTRODUCTION
   ============================================================

Insertion Sort is a simple comparison-based sorting algorithm.

It works in a similar way to organizing playing cards in your
hand. When you receive a new card, you compare it with the cards
you already have and insert it into the correct position.

The same principle is applied to an array.

The algorithm divides the array conceptually into two parts:

```
1. Sorted portion
2. Unsorted portion
```

At each iteration, one element from the unsorted portion is
selected and inserted into its correct position in the sorted
portion.

============================================================
2. OBJECTIVE
============

The objective of this implementation is to sort an array of
numbers in ascending order using the Insertion Sort algorithm.

For example:

```
Input:
[7, 3, 8, 2, 6, 4, 5]

Output:
[2, 3, 4, 5, 6, 7, 8]
```

============================================================
3. MAIN IDEA
============

The algorithm starts from the second element of the array.

Why?

Because the first element by itself is already considered
sorted.

For example:

```
[7, 3, 8, 2, 6, 4, 5]
 ↑
Sorted
```

Then we select the next element:

```
[7] | [3, 8, 2, 6, 4, 5]
 ↑          ↑
```

Sorted     Unsorted

The value 3 is called the "key".

We compare 3 with the elements in the sorted portion and
insert it into the correct position.

============================================================
4. ALGORITHM STEPS
==================

The algorithm follows these steps:

Step 1:
Start from index 1.

Step 2:
Store arr[i] in a variable called "key".

Step 3:
Set j = i - 1.

Step 4:
Compare arr[j] with key.

Step 5:
If arr[j] is greater than key, move arr[j] one position
to the right.

Step 6:
Decrease j by one and continue comparing.

Step 7:
When the correct position is found, insert key at arr[j + 1].

Step 8:
Repeat the process until the entire array is sorted.

============================================================
5. DETAILED EXAMPLE
===================

Consider this array:

```
[7, 3, 8, 2, 6, 4, 5]
```

---

## ITERATION 1

The first element 7 is considered sorted.

```
[7] | 3 8 2 6 4 5
```

We select:

```
key = 3
```

Compare 3 with 7.

Since:

```
7 > 3
```

Move 7 one position to the right:

```
[7, 7, 8, 2, 6, 4, 5]
```

Insert 3:

```
[3, 7] | 8 2 6 4 5
```

---

## ITERATION 2

The sorted portion is:

```
[3, 7]
```

The next element is:

```
key = 8
```

Compare 8 with 7.

Since:

```
7 < 8
```

No shifting is required.

The result is:

```
[3, 7, 8] | 2 6 4 5
```

---

## ITERATION 3

The sorted portion is:

```
[3, 7, 8]
```

The next element is:

```
key = 2
```

Compare 2 with 8.

```
8 > 2
```

Shift 8 to the right.

Then compare 2 with 7.

```
7 > 2
```

Shift 7 to the right.

Then compare 2 with 3.

```
3 > 2
```

Shift 3 to the right.

Insert 2:

```
[2, 3, 7, 8] | 6 4 5
```

---

## ITERATION 4

The next element is:

```
key = 6
```

Sorted portion:

```
[2, 3, 7, 8]
```

Compare 6 with 8:

```
8 > 6
```

Shift 8.

Compare 6 with 7:

```
7 > 6
```

Shift 7.

Compare 6 with 3:

```
3 < 6
```

Stop shifting.

Insert 6:

```
[2, 3, 6, 7, 8] | 4 5
```

---

## ITERATION 5

The next element is:

```
key = 4
```

Sorted portion:

```
[2, 3, 6, 7, 8]
```

Values greater than 4 are shifted to the right.

After insertion:

```
[2, 3, 4, 6, 7, 8] | 5
```

---

## ITERATION 6

The next element is:

```
key = 5
```

Sorted portion:

```
[2, 3, 4, 6, 7, 8]
```

Values greater than 5 are shifted.

After insertion:

```
[2, 3, 4, 5, 6, 7, 8]
```

The entire array is now sorted.

============================================================
6. JAVASCRIPT IMPLEMENTATION LOGIC
==================================

The main loop is:

```
for (let i = 1; i < arr.length; i++)
```

This means that we start from the second element.

The current element is stored:

```
const key = arr[i];
```

The previous position is stored:

```
let j = i - 1;
```

Then we compare elements:

```
while (j >= 0 && arr[j] > key)
```

If an element is greater than key, it is shifted:

```
arr[j + 1] = arr[j];
```

Then we move backward:

```
j--;
```

Finally, the key is inserted:

```
arr[j + 1] = key;
```

============================================================
7. WHY DO WE USE "j + 1"?
=========================

This is an important part of the algorithm.

During the while loop, larger elements are moved one position
to the right.

At the end of the loop, j has moved one position before the
correct insertion location.

Therefore, the correct position is:

```
j + 1
```

The key is inserted using:

```
arr[j + 1] = key;
```

============================================================
8. COMPLETE ALGORITHM
=====================

```
function insertionSort(arr) {

    for (let i = 1; i < arr.length; i++) {

        const key = arr[i];

        let j = i - 1;

        while (j >= 0 && arr[j] > key) {

            arr[j + 1] = arr[j];

            j--;
        }

        arr[j + 1] = key;
    }

    return arr;
}
```

9. IMPORTANT CHARACTERISTICS
============================

Insertion Sort has the following characteristics:

* It is a comparison-based sorting algorithm.
* It sorts the array in-place.
* It does not require an additional array.
* It builds the sorted sequence progressively.
* It is easy to understand and implement.
* It works particularly well for small or nearly sorted arrays.
* It is a stable sorting algorithm when implemented using
  the comparison condition shown in this project.

============================================================
10. TIME COMPLEXITY
===================

BEST CASE:
O(n)

The best case happens when the array is already sorted.

Example:

```
[1, 2, 3, 4, 5]
```

Each element only needs to be compared with the previous
element, so the algorithm performs approximately n operations.

AVERAGE CASE:
O(n²)

In a typical unsorted array, elements may need to be shifted
multiple positions.

Therefore, the average complexity is O(n²).

WORST CASE:
O(n²)

The worst case occurs when the array is sorted in reverse order.

Example:

```
[5, 4, 3, 2, 1]
```

Almost every element must be moved through the sorted section.

============================================================
11. SPACE COMPLEXITY
====================

The space complexity is:

```
O(1)
```

This means the algorithm uses a constant amount of additional
memory.

The algorithm only requires variables such as:

```
key
i
j
```

It does not create another array to store the sorted result.

============================================================
14. LIMITATIONS
===============

The main limitation is performance with large unsorted
datasets.

Because the average and worst-case complexity is O(n²),
Insertion Sort is generally less efficient than algorithms
such as:

```
- Merge Sort
- Quick Sort
- Heap Sort
```

for large datasets.

============================================================
15. CONCLUSION
==============

Insertion Sort is an important fundamental sorting algorithm
for understanding how sorting algorithms work.

The implementation progressively creates a sorted section
within the array.

At every iteration:

```
1. arr[i] is selected.
2. arr[i] becomes the key.
3. The key is compared with the previous elements.
4. Larger elements are shifted to the right.
5. The key is inserted into its correct position.
```

The process continues until all elements are sorted.

For the example:

```
[7, 3, 8, 2, 6, 4, 5]
```

the final result is:

```
[2, 3, 4, 5, 6, 7, 8]
```

This implementation satisfies the checkpoint requirement of
working with the first i - 1 elements as the sorted sequence
and inserting arr[i] into its correct position.
